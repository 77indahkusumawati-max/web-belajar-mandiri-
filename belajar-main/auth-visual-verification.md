# Verifikasi Autentikasi

Layar registrasi desktop menampilkan split layout ilustrasi dan form dengan hierarchy yang jelas. Pada mobile, ilustrasi disembunyikan agar form registrasi tetap ringkas dan mudah digunakan. Form menyediakan nama panggilan, email, kata sandi, tombol pendaftaran, mode login, dan akun demo. Build TypeScript dan produksi berhasil setelah perubahan.
